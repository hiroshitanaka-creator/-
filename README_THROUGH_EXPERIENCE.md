# 灰街の巡察官と嘘の地図：第一章〜第二章 通し体験強化版

この版では、第一章の結末を第二章の数値に反映するだけでなく、プレイヤーが「前章の判断を次章へ持ち込んだ」と感じられる導線を追加しています。

## 追加内容

- 第一章エンディング後の「第二章へ進む」ボタン
- 第一章の継承記録をlocalStorageへ保存してから第二章へ移動
- 第二章タイトル画面での継承検出表示
- 第二章開始時の5ページ章間ブリーフィング
- 第二章内の「シリーズ記録」タブ
- 第一章の回想ログ
- エルド救出、証人保護、雨鐘修復、完全推理の継承フラグ表示
- NPC信頼、噂圧、派閥姿勢の初期補正一覧
- シリーズ記録JSONの書き出し
- MCP Resource SnapshotへのseriesRecord公開

## 推奨プレイ

1. `haimachi_chapter1_transfer/index.html` を開く
2. 第一章を正式報告まで進める
3. 結末画面の「第二章へ進む」を押す
4. 第二章タイトルで「第一章を継承して始める」を押す
5. 章間ブリーフィングを見て第二章へ入る
6. プレイ中に「継」または `L` キーでシリーズ記録を確認する

## 注意

`file://` 直開きや別ドメインで遊ぶ場合、ブラウザ仕様によりlocalStorageの共有が不安定になる場合があります。その場合は第一章から継承JSONを書き出し、第二章タイトル画面で手動読み込みしてください。
