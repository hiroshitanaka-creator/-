# ゲームデザイン仕様

## 1. プレイヤーファンタジー

プレイヤーは、剣で敵を倒す英雄ではなく、**街に残す事実を選ぶ巡察記録官**です。

灰街では噂が十分な反復・恐怖・物質条件を得ると現実へ干渉します。したがって、真実を発見するだけでは街を救えません。証拠を集め、誰が何を信じているかを読み、公開順序を決め、誤情報を弱める必要があります。

## 2. 四つの設計柱

### 2.1 証拠は鍵ではなく、因果の部品

証拠を拾うだけでは推理は成立しません。各推理は、物証、時系列、動機、制度記録、証言などの異なる論理役割を要求します。

### 2.2 推理は世界状態を変える

成立した推理は、地図解放、NPC会話、敵の弱点、任務、正式報告の選択肢へ接続します。

### 2.3 失敗は巻き戻しではなく、街へ残る

時間経過、恐怖、噂圧、信頼、証人の状態が変わります。難易度「物語重視」を除き、調査を引き延ばすほど不利になります。

### 2.4 正しさと安全な公開は別問題

真相を即時公開することが常に最良ではありません。証人保護、危険区域の封鎖、物証保全が不足した状態での全面公開は、正しい報告でも悪い結末を生みます。

## 3. コアループ

```text
探索
→ 現場調査／会話
→ 証拠・信頼・時間の変化
→ 推理盤で因果を成立
→ 新区域・新会話・新任務を解放
→ 噂との論証戦
→ 街状態が変化
→ 正式報告
```

## 4. 第一章の事件構造

### 表層

北区で行商人エルドが失踪し、人名を喰う灰獣の噂が広まっています。

### 第1層：偽装

灰獣の足跡は、針金、木型、巡察靴の踏み跡によって作られています。

### 第2層：違法拘束

エルドは密売組織に殺されたのではなく、灰塩輸送を目撃したため巡察第七班に拘束されています。

### 第3層：事前準備された噂

灰獣警戒の公示、貼り紙、噂売りへの依頼は、失踪通報より前に準備されています。噂は事件を説明するためではなく、事件を覆うために流されました。

### 第4層：灰塩の機構

旧水路から採掘された灰塩は、人々が反復する具体的な像へ反応し、短時間の物理性を与えます。偽の灰獣説が、本物の噂獣を生みました。

### 第5層：利益循環

巡察長ダリオは、違法採掘で生まれた噂災害を自らの部隊に鎮圧させ、予算と昇進実績を得ています。隠蔽は一度の事件ではなく、災害を製造する仕組みです。

## 5. NPC設計

NPCは「真実を話す／嘘をつく」の二値ではありません。

- 真実を知っているが、報復を恐れて沈黙する
- 一部だけを見て誤解している
- 別人を守るため、自分へ疑いを向ける
- 事実を改ざんしたが、改ざん自体を内部告発の信号にする
- 嘘を商品として増幅するが、殺人までは望んでいない
- 制度上の正義を語りながら、利益循環を守る

信頼値は情報の自動解錠ではなく、会話選択肢、証人保護、告発後の生存可能性に影響します。

## 6. 推理設計

実装済みの推理は次の九つです。

1. 灰獣跡は人為的に作られた
2. 巡察隊がエルドを拘束した
3. エルドが恐れていたのは人間だった
4. 記録改ざんは内部告発の信号だった
5. 灰獣の噂は事件前から準備された
6. エルドは旧水路にいる
7. ダリオが隠蔽を指示した
8. 灰塩が噂を実体化させる
9. 事件全体は違法採掘・拘束・噂災害の複合構造である

後半推理は前半推理を前提とします。最終推理だけを直接成立させることはできません。

## 7. 論証戦

噂獣は、街で共有された命題を物理的な敵として表現したものです。

各敵は次を持ちます。

- 噂の強度
- 段階別の主張
- 証拠タグへの弱点・耐性
- 観察で開示される情報
- 群衆不安を高める攻撃
- 勝利時の世界状態変化

プレイヤーの敗北は死亡ではなく撤退です。平静を失い、時間が経過し、噂圧が増えます。証拠と推理は失われません。

## 8. 成長

経験値によって巡察官の階級が上がり、観察・共感・権限から一つを選んで強化します。

- 観察：調査判定、偽装検出、敵弱点の把握
- 共感：証言者との信頼、平静回復、群衆鎮静
- 権限：制限区域、押収・封印、行政的な被害抑制

単純な攻撃力上昇ではなく、事件への接近経路を変える成長です。

## 9. 難易度

### 物語重視

- 噂増加 0.58倍
- 調査判定 +1
- 期限による失敗なし
- 敵から受ける影響を軽減

### 巡察官

- 標準バランス
- 第8日が期限目安

### 灰街の夜

- 噂増加 1.38倍
- 調査判定 -1
- 誤判断の信頼損失が大きい
- 第7日が期限目安

## 10. 結末設計

結末は、単一の正解フラグではなく次の組み合わせで選ばれます。

- どこまで推理したか
- エルドを救出したか
- 証人保護を整えたか
- 噂災害を抑えたか
- 直接原因を何と認定したか
- 誰に主要責任を負わせたか
- どの順序で公開するか
- 街の安定度と北区の恐怖

最良結末「嘘を記した真実の地図」は、完全な真相、救出、証人保護、段階公開を要求します。

## 11. 完全版への展開

第一章のシステムを維持したまま、完成形では次を追加できます。

### 第二章：消された通りの住民

公式地図から消された街区を巡り、地図認証が行政サービス・所有権・住民存在へ与える影響を扱います。

### 第三章：二つの正しい証言

同一事件に対して矛盾する二つの証言が、どちらも観測者の位置からは正しい構造を扱います。

### 第四章：巡察官を記録する街

プレイヤー自身の過去報告がNPCの信念、派閥、敵、通行可能区域を形成します。

### 終章：灰街の原図

「公式に記録された事実が現実を安定させる」制度自体が、誰によって作られ、誰を排除してきたかを問います。

## 12. 長編化で守るべき制約

- 推理の答えを自由会話だけで決めない
- AI生成文を正式証拠にしない
- 事件真相は検証可能な状態グラフとして保持する
- 既存章の選択を新章へ反映するが、組み合わせ爆発を要約状態で制御する
- すべての事件に、探索・推理・世界状態変化の三要素を要求する
