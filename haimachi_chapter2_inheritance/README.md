# 灰街の巡察官と嘘の地図

## 第二章「黒雨の帳簿」

第一章で暴かれた「灰獣の嘘」は、灰街を救った。しかし、その正しい公式記録を利用して、今度は帳簿と地図が黒い雨に濡れ始める。

本作は、前作の後日談テキストではなく、**探索・証拠収集・会話・推理盤・噂との論証戦・正式報告・複数結末までを含む第二章プレイアブル版**です。外部ライブラリ、npm、APIキー、サーバー必須構成は不要です。

## ゲームの核

プレイヤーは灰街の巡察記録官として、黒雨で改ざんされる記録を保全しながら事件を追います。

```text
街を歩く
→ 黒雨で変化した記録・名簿・地図を調査する
→ NPCから証言・嘘・恐怖・利害を引き出す
→ 推理盤で帳簿、公債、影地図、黒鐘、名前消失を接続する
→ 噂が実体化した敵と論証戦を行う
→ 失踪者と証人を保護する
→ 公式報告で原因・責任主体・公開順序を選ぶ
→ 街の安定、住民の名前、次章への政治状況が変わる
```

単に「真相を当てる」だけでは最良結末になりません。黒鐘を止めず、証人保護や名前固定を整えずに全面公開すると、正しい報告でも住民名簿が消され、証拠隠滅と報復が発生します。

## 第二章の事件構造

### 表層

東区で黒い雨が降り、救済名簿・番地・公示の文字が変わる。街では「黒雨は第一章の真実への天罰」という噂が広がる。

### 第1層：黒雨は天候ではない

黒雨は窓の外から降っていない。公式文書の中に混ぜられた黒雨インクと灰塩粉が、指定された紙だけを濡らしている。

### 第2層：名前が帳簿から公債担保へ移される

救済名簿から消えた名前は、灰塩公債の担保欄に番号として再出現する。住民は失踪するのではなく、行政上「支払いを受けたことになった債務者」へ変換される。

### 第3層：公式地図と影地図が管轄を裂く

同じ東門でも、公式地図と影地図で到着する番地が変わる。救済窓口、監査庁、鋳造区が互いに「自分の管轄ではない」と逃げられる構造になっている。

### 第4層：黒鐘が記録改ざんを増幅する

黒鐘は雨を止める装置ではない。地図、名簿、公示を指定順に濡らす位相装置であり、鳴るたびに採用済み記録を再解釈させる。

### 第5層：公債・影地図・黒鐘による利益循環

黒雨被害が増えるほど復興公債の価値が上がり、対策予算が増え、その予算がまた黒鐘や封印へ戻る。事故対応ではなく、災害を継続させて利益を生む仕組みです。

## 起動方法

### 方法1：単一HTML版を開く

`dist/haimachi_chapter2_standalone.html` をダブルクリックしてください。

CSSとJavaScriptをすべて一つのHTMLへ内包しているため、サーバーやインストールは不要です。

### 方法2：付属ランチャーを使う

#### Windows

`start_windows.bat` をダブルクリックします。

#### macOS / Linux

```bash
chmod +x start_mac_linux.sh
./start_mac_linux.sh
```

ブラウザが自動で開かない場合は、次を開いてください。

```text
http://127.0.0.1:8080/
```

### 方法3：Pythonの標準サーバーを使う

```bash
python3 start_server.py
```

ポートを変える場合：

```bash
python3 start_server.py --port 9000
```

## 推理盤

推理は「証拠数」ではなく「論理役割」で成立します。

例：黒雨が記録を書き換えると証明するには、次のような異なる役割の資料が必要です。

1. 黒雨が紙の中から発生している物証
2. 改ざん対象が特定名簿に集中している記録
3. 黒雨前に装置・予算・表が準備されていた証拠

後半の推理には前半推理の成立も必要です。最終推理だけを直接選んで解決することはできません。

## 噂との論証戦

戦闘は通常のHP削りではなく、街で実体化した噂の主張を崩す論証戦です。

- 観察：現在の主張と弱点を読む
- 証拠提示：論点に合う物証・証言で噂の強度を下げる
- 推理固定：成立済みの因果関係をぶつける
- 鎮静：群衆不安を抑え、平静を立て直す
- 行政封印：権限を消費し、条件を満たした噂を固定・隔離する

同じ証拠を繰り返すと効果が急減します。噂は段階ごとに主張を変えるため、観察して論点を切り替える必要があります。

## 第一章からの継承

第二章タイトル画面の「第一章セーブ / 継承JSONを読み込む」から、第一章の結末到達後セーブ、または第一章の「第二章への継承データ」を読み込めます。読み込むと「第一章を継承して始める」ボタンが有効になります。

継承では、第一章の結末、エルド救出、証人保護、雨鐘修復、正式報告の公開方針を読み取り、第二章の初期状態へ次を反映します。

- ナイラ、エルド、イネス、オレンなどのNPC信頼
- 黒雨、エルド証言疑惑、名前債務などの噂圧
- 地図院、市民網、公債商会、監査庁、鋳造組合、噂売りの派閥姿勢
- 地区ごとの恐怖、信頼、治安、噂圧

第一章の座標、戦闘中状態、UI状態、未登録証拠の追加、任意パスの状態書き換えは採用しません。詳しくは `docs/SAVE_TRANSFER.md` を参照してください。

## MCP拡張境界

ブラウザ側には、将来MCP Serverと接続するための境界を残しています。

```javascript
window.haimachiMCP.getResourceSnapshot();
window.haimachiMCP.describeTools();
window.haimachiMCP.submitProposal(proposal);
```

AI/MCPが出せるのは、NPC記憶、噂候補、任務候補、派閥意図などの**候補**だけです。未登録証拠の捏造、任意状態パッチ、正式な世界状態の直接書き換えは拒否されます。
