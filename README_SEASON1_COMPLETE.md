# 灰街の巡察官と嘘の地図 第一部完結版

この版は、第一章「雨鐘の失踪者」と第二章・完結編「黒雨の帳簿と白紙選挙」を通しで遊ぶための完結版です。

## 追加された終局構造

```text
評議会中枢へ到達
→ 白紙選挙の仕組みを暴く
→ 黒雨帳簿を停止
→ 消えた名前を復元
→ 噂戦「灰街そのもの」と対峙
→ 終局報告
→ 分岐エピローグ
```

第2章で本編は一度完結します。ただし、外街・何年後・別時間軸という第3章の種をエピローグに残しています。

## 推奨プレイ順

1. `index.html` を開く
2. 第一章から開始
3. 第一章の正式報告後、「第二章へ進む」
4. 第二章で章間ブリーフィングを見る
5. 黒雨事件を進める
6. 評議会中枢・白紙票倉へ入る
7. 最終推理と噂戦「灰街公認記録」を突破
8. 終局報告でエピローグへ

## すぐ評価する場合

`haimachi_chapter2_inheritance/dist/haimachi_chapter2_standalone.html` を開き、第二章だけで始めてからデバッグAPIで確認できます。通常プレイでは第二章の前半推理を成立させることで評議会中枢が開きます。

## MCP境界

MCP/AIは候補を提出できますが、正式GameState・finalRecord・season1_completeを直接書き換える設計にはしていません。
