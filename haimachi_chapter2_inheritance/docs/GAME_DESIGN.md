# ゲームデザイン仕様 — 第二章「黒雨の帳簿」

## 1. プレイヤーファンタジー

プレイヤーは、敵を倒す英雄ではなく、**街に残す公式記録の形を決める巡察記録官**です。

第一章で正しい報告を残した結果、その「採用済みの真実」が次の隠蔽に利用されます。第二章では、黒雨で変わる帳簿、消える名前、二重化する地図、鳴るたび記録を濡らす黒鐘を追います。

## 2. 四つの設計柱

### 2.1 証拠は鍵ではなく、因果の部品

証拠を拾うだけでは推理は成立しません。黒雨の物性、名簿欠落、公債担保、影地図、黒鐘、証人保護を別々の論理役割として組み合わせます。

### 2.2 推理は地図と任務を変える

成立した推理は、新区域、NPC会話、噂戦の弱点、正式報告の説得力へ接続します。特に「鏡面水路」は、影地図の推理を成立させないと正式な線として復元されません。

### 2.3 失敗は巻き戻しではなく、名簿へ残る

時間経過、恐怖、噂圧、信頼、証人状態が変わります。調査を引き延ばすほど、名前が公債担保へ移され、証拠保全が難しくなります。

### 2.4 正しさと安全な公開は別問題

真相を即時公開することが常に最良ではありません。ミラ救出、名前固定、証人保護、黒鐘停止が不足したまま全面公開すると、正しい報告でも報復と名簿消去が発生します。

## 3. コアループ

```text
探索
→ 黒雨記録の調査／会話
→ 証拠・信頼・時間の変化
→ 推理盤で因果を成立
→ 新区域・新会話・新任務を解放
→ 噂との論証戦
→ 名前保護・黒鐘停止・証拠保全
→ 正式報告
```

## 4. 第二章の事件構造

### 表層

東区で黒雨が降り、救済名簿と番地が変化します。人々は第一章の真実を「天罰」として語り始めます。

### 第1層：黒雨は天候ではない

雨は空からではなく、公式文書の内部から発生します。黒雨インクと灰塩粉により、特定の帳簿だけが濡れます。

### 第2層：名前の債務化

救済名簿から消えた名前は、公債担保の番号欄へ移されます。これは住民の失踪ではなく、存在の会計処理です。

### 第3層：影地図による管轄分断

公式地図と影地図が同じ門を別の番地へ接続し、救済窓口・監査庁・鋳造区が責任を互いに押し付けられる構造を作っています。

### 第4層：黒鐘の位相装置

黒鐘は雨を止めるものではなく、紙中の灰塩を逆相で震わせ、地図・名簿・公示を指定順に濡らす装置です。

### 第5層：制度化された利益循環

黒雨被害が増えるほど復興公債の価値が上がり、対策予算が増え、その予算がまた黒鐘・封印・救済券再発行費へ戻ります。

## 5. NPC設計

NPCは「真実を話す／嘘をつく」の二値ではありません。

- 正しいが証拠として弱い体験談を持つ
- 自分の名が消える恐怖で証言を控える
- 実行者だが設計者ではない
- 利益を得ているが災害の全体像を知らない
- 内部告発者だが保護なしでは証言できない
- 技術責任を負うが政治承認には触れられない

信頼値は情報の自動解錠ではなく、会話選択肢、証人保護、報告後の生存可能性に影響します。

## 6. 推理設計

実装済みの推理は次の十個です。

1. 黒雨は天候ではなく記録を変える
2. ミラは予算ではなく消えた名前を追っていた
3. 名前は救済名簿から公債担保へ移される
4. 二重門と影地図が管轄を分断している
5. 黒雨被害と公債利益は循環している
6. 黒鐘は黒雨改ざんを増幅する位相装置である
7. 鏡面水路は影地図の線で復元できる
8. マレンは主犯ではなく責任を吸わせる緩衝材である
9. 閉鎖評議が影地図と黒鐘を承認した
10. 第二章事件は公債・影地図・黒鐘による制度的記録災害である

後半推理は前半推理を前提とします。最終推理だけを直接成立させることはできません。

## 7. 論証戦

第二章の敵は、黒雨により実体化した社会的命題です。

- 黒雨の群衆：第一章の真実を天罰として反転させる
- 利息蛾：名前を金利と担保へ変換する
- 黒鐘の反響：地図・名簿・公示を三拍で濡らす
- 鏡面名簿：消えた人々を存在しなかったことにする

敵は噂の強度、段階別の主張、証拠タグへの弱点・耐性、群衆不安を持ちます。

## 8. 成長

経験値によって巡察官の階級が上がり、観察・共感・権限から一つを選んで強化します。

- 観察：黒雨で変わった文字、位相のズレ、帳簿の消し跡を見抜く
- 共感：名前を消された人々を証人として扱い、保護しながら証言へつなぐ
- 権限：監査命令・封印・資料差押えを使い、制度側の壁を開く

## 9. 結末設計

結末は、単一の正解フラグではなく次の組み合わせで選ばれます。

- どこまで推理したか
- ミラを救出したか
- 名前固定を整えたか
- 証人保護を整えたか
- 黒鐘を停止したか
- 直接原因を何と認定したか
- 誰に主要責任を負わせたか
- どの順序で公開するか
- 街の安定度と噂圧

最良結末「黒雨をほどく白地図」は、完全な真相、ミラ救出、名前固定、証人保護、黒鐘停止、段階公開または監査囮を要求します。

## 10. 次章への展開

第二章の結果により、第三章では次を拡張できます。

- 公式記録を失った住民の自治組織
- 評議院内部の派閥分裂
- 黒雨技術の転用事件
- プレイヤーの報告書を根拠に動く派閥AI
- MCP接続時のNPC長期記憶と行政記録Resource
