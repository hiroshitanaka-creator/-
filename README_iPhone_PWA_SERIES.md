# iPhone / PWAで遊ぶ方法

1. このフォルダ全体をGitHub Pages、Netlify、Vercel、Cloudflare PagesなどHTTPS環境へ配置します。
2. iPhoneのSafariで `index.html` を開きます。
3. 共有ボタン → 「ホーム画面に追加」を選びます。
4. ホーム画面の「灰街 通し版」から起動します。

注意：`file://` で直接開いた場合、iPhoneでは正式なPWAインストールになりません。第一章から第二章への自動継承が不安定な場合は、第一章の結末画面から継承JSONを書き出し、第二章タイトル画面で手動読み込みしてください。
